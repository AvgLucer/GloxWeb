## ✨ What is GloxWeb?

GloxWeb is an AI-powered frontend builder that transforms structured website instructions into complete, polished website interfaces using OpenRouter's free AI models.

It is designed to help you build professional-looking, non-generic website frontends in approximately 1–2 hours.
