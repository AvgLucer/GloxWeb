## 🚀 About GloxWeb

GloxWeb is an AI-powered frontend builder that transforms structured website instructions into complete, polished website interfaces using free AI models available through OpenRouter.

It helps users create professional-looking, non-generic website frontends in approximately 1–2 hours.

## ✨ Core Features

- **AI Frontend Generation:** Generate complete website frontend projects.
- **Structured Instructions:** Organize requirements into dedicated sections.
- **Custom Architecture:** Define pages, layouts and website structure.
- **Theme and Design:** Control the visual identity of generated websites.
- **Feature Planning:** Specify interactions and functionality.
- **Extra Instructions:** Add custom implementation requirements.
- **OpenRouter Integration:** Access supported AI models through OpenRouter.

## ⚙️ Installation & Setup

### 1. Install Python

Ensure Python is installed and accessible from your terminal.

### 2. Open the SRC directory

```bash
cd GloxWeb/SRC
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch GloxWeb

```bash
python gloxweb_build.py
```

### 5. Configure OpenRouter

Provide your OpenRouter API key through the application's supported configuration method, then select an available model.

*Note: Exact dependency requirements and API configuration depend on the implementation in `gloxweb_build.py`.*

## 📋 Generation Workflow

GloxWeb uses the following structured input system:

| Section | Purpose |
|:---|:---|
| **Project Name** | Website project identity |
| **Website Architecture** | Pages, sections and structure |
| **Theme and Design** | Colors, typography and visual direction |
| **Features and Interaction** | Functionality and user interactions |
| **Extra Instructions** | Additional requirements and constraints |

## ⚠️ Development Notes

- AI generation may take time to initialize.
- Generation time depends on model availability and complexity.
- Occasional AI-generated code errors may occur.
- Always review and test generated frontend projects.
- OpenRouter model availability and free-tier limits may change.
